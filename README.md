## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to the output directory. The image itself is drawn by `build_image.py` (Python + Pillow, run locally while building the entry; the grader only runs `main.ts`).
